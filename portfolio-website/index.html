Road Accident Protocol System

Python • TensorFlow • CNN • Twilio API • GPS

Project Architecture & Overview

This project is an intelligent emergency protocol system designed to eliminate delay in accident detection and emergency response dispatch. Using acoustic frequency pattern recognition powered by Convolutional Neural Networks, the system identifies collision sound signatures in real-time.

Key Technical Contributions:

  • Audio Feature Engineering: Collected and preprocessed a diverse dataset of over 10,000+ acoustic crash and environmental noise audio samples.
  • Deep Learning Model: Built and trained a 2D CNN architecture on spectrogram features, achieving an impressive 85% classification accuracy.
  • Automated Emergency Pipeline: Integrated Twilio SMS API and GPS coordinates lookup to trigger immediate, automated alert dispatches to registered emergency contacts and nearby medical facilities upon accident confirmation.
  • Iterative Optimization: Tuned model hyperparameters and noise filtering layers to minimize false-positive detections.
